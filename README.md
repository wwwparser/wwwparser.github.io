# wwwparser.github.io

Корневая страница GitHub Pages аккаунта. Нужна для двух вещей:

1. По адресу `https://wwwparser.github.io/` открывается список проектов,
   а не 404.
2. В корне хоста лежат файлы подтверждения прав для Яндекс.Вебмастера
   и Google Search Console — без них Яндекс не принимает сайты,
   лежащие в подпапках (например `/selecline-bm1250c/`).

Файлы подтверждения кладутся в корень репозитория как есть,
рядом с `index.html`.
